# Marca WTA

Vetorizada em 11 de outubro de 2026 a partir do PNG enviado pelo responsável (1024 × 348 px), porque não havia arquivo vetorial.

| Arquivo | Uso |
| --- | --- |
| `wta-logo-escuro.svg` | Logo completo para fundo escuro: marca laranja, assinatura branca |
| `wta-logo-claro.svg` | Logo completo para fundo claro: assinatura em `#051628` |
| `wta-marca.svg` | Só a marca "WTA", para menu e cabeçalhos |
| `wta-icone.svg` | Ícone compacto e favicon: o W laranja sobre quadrado azul |
| `*.png` | Exportações em alta resolução com fundo transparente (logos a 3x, ícones em 512, 180 e 32 px) |

Como foi feito:

- **Marca.** Redesenhada com geometria exata a partir das medidas do original: hastes de 49 unidades, barras de 44, raio de 36 nos cantos externos do A. Fica igual ao original, com bordas limpas em qualquer tamanho.
- **Assinatura.** "Gestão e Automações" em Poppins Regular (licença SIL Open Font), convertida em curvas, com tamanho e espaçamento ajustados letra a letra ao original. Não depende de fonte instalada.

Cores: laranja `#FF6600`, azul `#051628`.

Se existir o arquivo original do designer (AI, SVG, PDF ou EPS), ele deve substituir estes.
